# defer 和 async 完整区别（面试满分版，超好记）
先记住核心一句话：
**都能让 JS 不阻塞 HTML 解析；区别在：下载时机、执行顺序、执行时机、DOMContentLoaded 影响。**

---

## 一、基础共同点
1. 都是用来**异步加载 JS 文件**
2. 加载期间**不会阻塞 HTML 解析、不会阻塞渲染**
3. 只针对「外部 script 引入」，内联脚本无效

```html
<script src="a.js" async></script>
<script src="b.js" defer></script>
```

---

## 二、核心 5 大区别（必背）
### 1. 下载时机
- **async**：
  HTML 解析过程中，**立刻异步开始下载 JS**
- **defer**：
  HTML 解析过程中，**同样异步下载 JS**
👉 **下载时机两者一样**

---

### 2. 执行时机（最大区别）
- **async**
  脚本**下载完成立刻执行**，不管 HTML 是否解析完
- **defer**
  脚本下载完**不立刻执行**，等到：
  **HTML 全部解析完毕 → 再按顺序执行**

---

### 3. 多个脚本执行顺序
- **async**：**无序**
  谁先下载完，谁先执行，代码依赖容易报错
- **defer**：**有序**
  按标签书写顺序执行，保证依赖关系

---

### 4. 与 `DOMContentLoaded` 关系
- **async**：
  JS 下载完就插空执行，**可能在 DOM 就绪前/后**
- **defer**：
  所有 defer 脚本**全部执行完，才触发 DOMContentLoaded**

---

### 5. 适用场景
- **async**
  独立脚本、无依赖、统计、埋点、广告、第三方插件
- **defer**
  有先后依赖、操作 DOM、项目业务主 JS

---

## 三、执行流程图解（极简理解）
1. 普通 script：
   解析HTML → 暂停 → 下载+执行JS → 继续解析HTML
2. async：
   解析HTML + 后台下载JS并行 → 下载完成**插队执行**
3. defer：
   解析HTML + 后台下载JS并行 → HTML解析完 → 顺序执行JS

---

## 四、极简背诵口诀
1. 下载：两者一样，异步不阻塞
2. 执行：
   - async：**下完就跑，乱序**
   - defer：**等页面，有序**
3. DOM 事件：
   - defer 等脚本跑完才触发 DOMContentLoaded
4. 选型：
   - 无依赖用 async
   - 有依赖、操作 DOM 用 defer

---

## 五、高频面试问答
Q：为什么有依赖的 JS 不能用 async？
A：
async 下载完成就立即执行，多个脚本**执行顺序不可控**，
如果 a 依赖 b，a 先下载完就会直接报错。
defer 按标签顺序执行，保证依赖正常。

（普通script / defer / async）** # script / defer / async 完整对比表（面试直接背）
## 一、总表（满分背诵）
| 特性 | 普通 `<script>` | **defer** | **async** |
|------|----------------|-----------|-----------|
| 下载方式 | 同步阻塞 | 异步后台下载 | 异步后台下载 |
| 是否阻塞HTML解析 | ✅ 阻塞 | ❌ 不阻塞 | ❌ 不阻塞 |
| 执行时机 | 加载完**立即执行** | HTML解析完毕后执行 | 文件下载完成**立刻插队执行** |
| 多文件执行顺序 | 从上到下有序 | **按标签书写顺序 有序** | **谁先下完谁先执行 无序** |
| 延迟执行 | 无 | 延迟到DOM解析完 | 不延迟，下载完就跑 |
| 影响 DOMContentLoaded | 阻塞 | **全部执行完才触发** | 不等待，互不影响 |
| 依赖关系 | 支持依赖 | 支持先后依赖 | **不支持依赖，易报错** |
| 适用场景 | 关键首屏必须优先执行 | 业务代码、有依赖、操作DOM | 独立脚本、埋点、广告、统计 |

---

## 二、执行流程（秒懂）
1. **普通 script**
HTML解析 → 暂停 → 下载JS → 执行JS → 继续解析HTML

2. **defer**
HTML解析 ⇄ 异步下载JS
→ 等HTML全部解析完
→ 按顺序执行所有 defer 脚本
→ 触发 DOMContentLoaded

3. **async**
HTML解析 ⇄ 异步下载JS
→ 一旦JS下载完成，**立刻暂停HTML，插队执行**
→ 执行完继续解析，和 DOMContentLoaded 无关

---

## 三、核心考点 3 句话
1. **下载**：`defer`、`async` 都是**异步并行下载**，都不阻塞页面渲染。
2. **顺序**：
- defer：**有序**
- async：**乱序**
3. **时机**：
- defer：**等DOM完事再执行**
- async：**下完马上执行**

---

## 四、开发使用建议
- 业务JS、框架代码、操作DOM、有依赖：用 **defer**
- 第三方独立插件、监控、埋点、广告：用 **async**
- 尽量少用无属性普通 script，容易阻塞首屏

---

## 五、极简口诀（快速记忆）
- defer：**后台下，排队跑，等DOM，不乱序**
- async：**后台下，跑完就，插队走，乱顺序**
